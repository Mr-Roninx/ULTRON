# ULTRON-SWU-1.4 Counterfactual Model

## 1. 5-Branch Civilization Forking
1. `CONTROL_NO_ULTRON`: Passive baseline capturing natural self-recovery (~36.2%).
2. `RULE_BASED`: Fixed heuristics.
3. `ULTRON_LLM_OFF`: Deterministic semantic planner without LLM diagnosis.
4. `ULTRON_LLM_ON`: LLM semantic candidate ranking.
5. `ULTRON_FULL`: Full adaptive multi-opportunity recovery + economic translation.

Aligned with **Common Random Numbers (CRN)** to eliminate stochastic noise from treatment effects.
