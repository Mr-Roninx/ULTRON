# ULTRON Synthetic Payment Universe v1.3 Specification
**Codename: ULTRON-SWU-1.3 (Persistent Economic Civilization Engine)**

## 1. System Overview
ULTRON-SWU-1.3 extends the synthetic financial world into an evolving, continuous economic civilization across multi-day and multi-month simulation horizons ($T+0$ to $T+365$ days).

---

## 2. Invariant Rules
1. **Three-Domain Separation**: `WORLD` (complete reality), `AGENT` (observable slice at $t \le T$), `EVALUATOR` (latent oracle, future outcomes, counterfactuals).
2. **Deterministic Financial Authority**: The LLM remains semantic advisor; all money movements occur via `CivilizationDoubleEntryLedger`.
3. **Continuous Organic Activity**: Subscriptions auto-renew, invoices age, customers experience cashflow cycles, and gateways react to congestion.
4. **End-to-End Provenance**: Every recovered rupee is backed by an unbroken causal and accounting chain.
