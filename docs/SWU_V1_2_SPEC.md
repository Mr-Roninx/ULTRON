# ULTRON Synthetic Payment Universe v1.2 Specification
**Codename: ULTRON-SWU-1.2**

## 1. System Overview
ULTRON-SWU-1.2 transforms the synthetic payment universe from a static dataset into a **large-scale, persistent, temporal, causally consistent financial world simulator**.

---

## 2. Invariant Principles
1. **Three-Domain Separation**: `WORLD` (simulation state), `AGENT` (observable slice at $t \le T$), `EVALUATOR` (ground truth oracle & counterfactuals).
2. **Deterministic Financial Authority**: The LLM acts as an intelligence advisor; all monetary balance mutations occur strictly through the simulated double-entry ledger.
3. **Temporal Causality**: Chronological priority queue processing with delayed event consequences.
4. **Counterfactual Isolation**: 5-branch world forking using common random numbers.
