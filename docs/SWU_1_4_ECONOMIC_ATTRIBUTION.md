# ULTRON-SWU-1.4 Economic Attribution

## 1. Incremental Causal Attribution
$$\text{Incremental Recovery} = \text{Recovery}_{\text{ULTRON}} - \text{Recovery}_{\text{Control}}$$
$$\text{Incremental NEV} = \text{Incremental Recovery} - \text{Operational Cost}$$

Natural recovery (issuer batch clearing) is strictly deducted to prevent false attribution of organic recoveries to agent actions.
